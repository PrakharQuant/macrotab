# Local dataset setup

For local development, place an authorized GMD file at `data/GMD.csv`, or set `MACROPULSE_DATA` to its path. The raw CSV is intentionally git-ignored and must not be committed. The source is the Global Macro Database by Müller, Xu, Lehbib, and Chen (2025); see the [citation](https://www.globalmacrodata.com/research-paper.html) and [Research Use Terms](https://www.globalmacrodata.com/license.html).

The GMD terms restrict republishing GMD data or derived data on another website or service without written approval. Do not switch a public deployment to automatic live GMD retrieval until its use is authorized. The official [Anansi MCP endpoint](https://mcp.anansidata.com/mcp) is documented for AI-agent clients and uses account authorization; connecting it to Manus does not pass its credentials to Streamlit Cloud or bypass the GMD terms. GMD also documents a [Python package](https://github.com/KMueller-Lab/Global-Macro-Database-Python) for direct data access; using that package in a public app would still need to satisfy the same terms.

The loader retains rows from 1960 through 2031. Years before 1960 are excluded from this project's analysis window. Years through 2024 are treated as the historical research sample; 2025–2031 are displayed as a forward/forecast period and are not used as crisis-model outcomes. These cutoffs are explicit project assumptions, not dataset-provided provenance claims.
